# Week 11_1 — React components and props

This React app covers the three Week 11_1 exercises and both homework tasks,
including default props, conditional notification lists, children composition,
student profile cards, and a technology-filtered project gallery. The production
build is written to `dist/`; the small `index.html` in this folder forwards
GitHub Pages visitors to it.

The project gallery is shared with the repository's root `portfolio.html`.
Builds output the gallery widget alongside the coursework app.

```sh
npm install
npm run dev
npm run build
```
