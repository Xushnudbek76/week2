# Week 11 — React components and props

This page is a React app built with Vite. The production build is written to
`dist/`; the small `index.html` in this folder forwards GitHub Pages visitors to it.

```sh
npm install
npm run dev
npm run build
```

The student directory includes sample classmates and a GPA prompt. Replace the
sample classmates and add your GPA if your assignment requires real records.
