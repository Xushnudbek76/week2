What is the DOM?

The browser turns HTML into a tree of objects. JavaScript can find and change those objects while the page is open.

HTML source

<main>
  <h1>Hello</h1>
  <p>World</p>
</main>

DOM tree

document └── html └── body └── main ├── h1 │ └── "Hello" └── p └── "World"

Each tag and text value becomes a node that JavaScript can access.
